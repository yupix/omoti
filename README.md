# Omoti

Antigravityで開発中の動画編集サイト

## 実行方法

```
pnpm i

pnpm dev
```

## Command Code で AI 動画を生成する

AI Video Generator の「AI Provider」で「Command Code」を選択し、API キーを入力します。
サーバー側で設定する場合は `.env.local` に `CMD_API_KEY=...` を追加して開発サーバーを再起動し、画面の API キー欄は空にします。

「Model ID」は省略すると `deepseek/deepseek-v4-flash` を使用します。
[対応モデルの ID](https://commandcode.ai/docs/reference/cli/models) を指定して変更できます。
Claude は Messages API、それ以外は Chat Completions API に自動で接続します。
利用には API アクセスが有効なキーが必要です。詳細は [Command Code Provider API](https://commandcode.ai/docs/provider) を参照してください。

プロバイダー連携のテストは Node.js 24.1 以降で `pnpm test` を実行します。外部 API はモックされ、課金は発生しません。


## AI 生成のレイアウト検証

生成した台本の文字同士の重なり・コード／プレビュー／立ち絵との重なり・画面外へのはみ出し・字幕領域への侵入を検査し、問題がある場合は具体的な指摘と直前の台本を AI に返します。初回生成後に最大3回修正し、解消しなければエラーを表示してタイムラインには取り込みません。認証・通信エラー時もサンプル動画への置き換えは行いません。

同時表示するクリップは前後関係を保ちながら別トラックに配置し、取り込み前にも時間の重複を検査します。長い字幕は最大2行ずつに分割し、表示時間を音声の長さに合わせて文字数で配分します（単語単位の音声認識による同期ではありません）。文字は描画時にも枠内に収まるサイズへ調整します。


## PSD のアップロード

「素材」のアップロード欄で `.psd` を選択するか、ファイルをドロップしてください。1ファイルの上限は 1 GiB です。転送量・進捗・保存中の状態が画面右下に表示され、途中で中止できます。2分間進捗がない場合は通信を中止してエラーを表示します。

大きなファイルは受信しながら保存し、完了したファイルだけライブラリに表示します。PSD の縦横サイズはアップロード元のヘッダーから読み取るため、保存直後に PSD 全体をダウンロードし直しません。ページを再読み込みすると、保存済みの素材を再取得できます。

AI 生成では見出し・本文パネル・字幕の領域を分け、検証とクリップ作成に同じ配置計算を使います。文字を潰す縁取りや長すぎるコードも AI に修正させます。コード表示はフレームに連動し、構文色分けに失敗しても本文を表示します。これらの配置ルールは新しく生成する動画に適用されます。

PSD はクリップ・設定画面で読込を共有し、表示するレイヤーだけ描画用キャンバスを作ります。通信失敗時はプレビューから再読み込みできます。PSD を読めない状態の書き出しは、エラー表示を動画に焼き込まず失敗として扱います。

## AI による PSD の表情選択

キャラクター追加時と生成前に、PSD の親子関係・レイヤー名・初期表示を解析します。画像は AI に送信しません。体・髪・服などの初期パーツを保持し、AI は実在するパーツから表情を選びます。同名レイヤーや名前に `/` を含むレイヤーも別々に扱います。

[PSDTool の `*` による選択切り替え](https://oov.github.io/psdtool/manual.html)や目・口・眉のグループをもとに、競合する差分、固定パーツの欠落、存在しないパーツを検査します。問題は既存の修正ループで AI に返し、解消しない場合は動画へ取り込みません。独立した口の差分を確認できない場合は、口パクを無理に付けず固定表示にします。名前だけで判別しづらい差分は初期表示を優先する指示で、見た目を画像認識しているわけではありません。

既存の設定を初期表示から作り直すには、AI 生成画面で対象キャラクターの「構造を再解析」を押してください。入力する構造は1ファイルあたり10,000レイヤーまで検証します。設定に存在しないパーツや、複数の衣装を同時に必須指定した矛盾がある場合は、AI を呼び出す前にエラーを表示します。
