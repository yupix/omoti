# 合成音声エンジン 連携ガイド

このドキュメントでは、新しい合成音声（TTS）エンジンを Omoti エディタに統合するための要件とレスポンス形式について説明します。

## アーキテクチャの概要

システムは主に2つの方法でTTSエンジンとやり取りします：
1. **メタデータの取得**: UIでキャラクター設定を表示するために、利用可能な話者やプリセットを取得します。
2. **音声の合成**: テキストを音声ファイルに変換し、タイムライン同期のためにクリップのメタデータを返します。

統合は通常、`app/api/synthesize/` にある内部APIプロキシを通じて管理されます。

---

## 1. メタデータAPIの要件

キャラクター設定ダイアログで選択肢を表示するために、エンジンは利用可能な音声のリストを提供する必要があります。

### リクエストパターン
`GET /api/synthesize/metadata?provider=[エンジン名]&baseUrl=[サーバーURL]`

### 期待されるレスポンス形式

#### プリセットベースのシステム (例: AIVOICE)
プリセット名を表す文字列の配列を返してください。
```json
[
  "プリセット名1",
  "プリセット名2"
]
```

#### 話者/スタイルベースのシステム (例: VOICEVOX)
スタイルがネストされた話者オブジェクトの配列を返してください。
```json
[
  {
    "name": "話者名",
    "speaker_uuid": "一意のID",
    "styles": [
      { "id": 0, "name": "ノーマル" },
      { "id": 1, "name": "あまあま" }
    ]
  }
]
```

---

## 2. 音声合成APIの要件

音声合成プロセスでは、音声ファイル（通常は `.wav` または `.mp3`）を生成し、タイムライン同期のためにその再生時間を返す必要があります。

### リクエストパターン
`POST /api/synthesize`
Body:
```json
{
  "provider": "エンジン名",
  "baseUrl": "http://...",
  "text": "読み上げるテキスト",
  "voiceSettings": {
    "speakerId": 0,      // またはプリセット名
    "styleId": 1         // オプション
  }
}
```

### 期待されるレスポンス形式
内部プロキシは、永続的なURLと再生時間を含むJSONオブジェクトを返す必要があります。

```json
{
  "url": "/uploads/synth-1234.wav",
  "duration": 4.5,
  "filename": "synth-1234.wav"
}
```

#### 主要なフィールド:
- **`url`**: ブラウザからアクセス可能なURL。エンジンが一時ファイルを生成した場合は、ページのリロードや Remotion のレンダリングで消えないよう、プロキシ側で `public/uploads/` に移動させてください。
- **`duration`**: **重要。** 音声の長さ（秒単位）。Remotion が `durationInFrames` を計算するために必要です。
- **`filename`**: サーバーに保存されたファイル名。

---

## 3. 実装のベストプラクティス

### 音声フォーマット
- Remotion およびブラウザの `AudioContext` との互換性を最大限に高めるため、**WAV (44.1kHz または 48kHz)** を使用してください。
- ストリーミングレスポンスは避け、静的アセットとして返してください。

### 再生時間の計算
エンジンがレスポンスで再生時間を返さない場合は、内部プロキシ側で計算する必要があります。
WAVファイルの場合、ヘッダのバイトレートから計算できます：
```typescript
function getWavDuration(buffer: Buffer): number {
    const byteRate = buffer.readUInt32LE(28);
    const dataSize = buffer.readUInt32LE(40);
    return dataSize / byteRate;
}
```

### エラーハンドリング
- エラー時は `{ error: "..." }` という形式のJSONで具体的なエラーメッセージを返してください。
- 接続タイムアウトなどは適切に処理し、クライアントがフリーズせずに「サーバーがオフラインです」といったメッセージを表示できるようにしてください。

---

## 4. 統合時のチェックリスト

新しいエンジンを追加する場合、以下のファイルを更新する必要があります：
1. `components/editor/AiGeneratorDialog.tsx`: キャラクターの「音声」タブに新しいエンジンを追加。
2. `app/api/synthesize/route.ts`: `POST` リクエストのプロキシロジックを追加。
3. `app/api/synthesize/metadata/route.ts`: `GET` リクエストのプロキシロジックを追加。
4. `app/api/ai/generate/route.ts`: AIジェネレーターが動画の一括生成時に新しいエンジンを使用できるように対応。
